# RunSpace
RunSpace is a platform where coding finally gets sought after it deserves. Usually when you try to code or test something, it feels like everything is hiding behind programs, installations, or even rules that is stopping you from doing whatever you want. But RunSpace breaks those limits because you can write, upload and even run your code directly on the website without anything holding you back. 

RunSpace is a place where code finally gets the freedom it deserves. Usually when you try to write or test something, it feels like everything is locked behind programs, installations, or rules that stop you from doing what you want. But RunSpace breaks those limits, because you can write, upload, and run your code directly on the website without anything holding you back.


RunSpace was made because alot want to show their projects, test their ideas or create something simple without spending hours or even day to fix setups. Other platforms feel strict and complicated, but RunSpace let's you run your code instantly, no programs installed on your computer. Almost like the platform wants you to experiment and be creative. You can also share links to your projects so other can see what you have done, they can see it, test it, and even chat with you directly, which amakes it feel more alive and secured.

There are good things when you code in RunSpace: It gives you freedome to code. But of corse there will be limits, lower fps and restricted code length, but these limits exists for a reason, to keep things safe, simple and fast for everyone. RunSpace isn't used for big projects nor demanding programs.It's meant for quick ideas, learning and testing, and that's what makes it so strong. It becomes a symbol of how coding can be free and easy when nothing hides. 


Please note: This is just the front-End, we will never release the back-end, for security reasons. Do not run this files locally, it will just become worse, this github page is to see what actually is behind the code.
